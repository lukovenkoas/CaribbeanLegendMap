# Интерактивная карта Вест-Индии (Caribbean Legend)

Открыть `index.html` в браузере (двойным кликом, сервер не нужен).

## Что умеет
- Колесо — масштаб, перетаскивание — сдвиг, ⤢ — вписать карту. Правый клик — точка с широтой/долготой.
- Слои: острова, регионы (материк и части Кубы/Эспаньолы), поселения (флажок нации, фильтр по нациям),
  маяки, места высадки, скрытые квестовые острова, свои метки. Подписи бухт появляются при приближении
  (или всегда — галочка в «Вид»).
- Поиск по названию на RU/EN и по id; «фильтровать карту» оставляет на карте только найденное
  (найден остров — показывается и всё, что на нём).
- Клик по объекту — карточка: координаты, нация, что на острове, карты-предметы (обычные и адмиральские) — клик открывает карту.
- Широта/долгота → точка на карте (формула игры, `Program\worldmap\worldmap_coords.c`).
- Фон: очищенная карта или «Отличная карта» игры с надписями; слой границ акваторий; сетка.
- Адрес страницы запоминает выбор: `index.html#sel=island:Jamaica`, `#ll=15.4667,63.4667`, `#q=бухта`.

## Файлы
| Файл | Что |
|---|---|
| `index.html`, `map.css`, `map.js` | страница |
| `data.js` | **генерируется** `_build\build.py` из файлов игры — руками не править |
| `extra.js` | свои метки (пример внутри) — правится руками |
| `img\map_clean.jpg` | очищенная карта (2048², из `C:\Downloads\_process\map_good-4.jpg`) |
| `img\ru`, `img\en` | карты из игры (`Resource\Textures\Interfaces\Maps\<язык>`), `img\boundaries.png`, `img\flags` |
| `_build\build.py` | сборщик данных; `_build\tx2img.py` — конвертер текстур `.tga.tx` |

## Откуда данные
- Позиции: `Program\worldmap\worldmap_init.c` (`worldMap.islands.<регион>.<локация>.position`).
- Названия: `Resource\INI\texts\{russian,english}\LocLables.txt`; острова ↔ регионы: `Program\islands\islands_init.c`.
- Нации на начало игры: `Program\colonies\Colonies_init.c`. Карты-предметы: `Program\items\initItems.c` (`InitStdMap`).
- Привязка к картинке: точки поселений на очищенной карте подогнаны к координатам мира (погрешность ~10 px из 2048 —
  точки на карте ставил художник). Марун-Таун своей метки на глобальной карте не имеет — позиция взята с бумажной карты.
- Скрытые острова (Ксочитэм, Хаэль Роа и др.) — координаты условные (стоят на сетке 2048/24).

## Пересборка (после обновления игры)
```
python -I Map\_build\tx2img.py Resource\Textures\Interfaces\Maps\russian Map\img\ru
python -I Map\_build\tx2img.py Resource\Textures\Interfaces\Maps\english Map\img\en
python -I Map\_build\build.py
```
(из папки игры; нужны Pillow, numpy, scipy. Слой границ после конвертации перенести: `img\ru\map_good_boundaries.png` → `img\boundaries.png`.)
